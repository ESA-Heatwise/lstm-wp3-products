# HeatWise ATI

This product computes Apparent Thermal Inertia (ATI) from day/night LST and reflectance inputs using the method of [Mandanici et al. (2024)](https://www.nature.com/articles/s41598-024-64371-3)

## Usage

- Build the EOAP/CWL workflow using ['xcengine'](https://github.com/xcube-dev/xcengine) and executing `./build.sh` or by using the provided `Dockerfile` in `.\app`.
- Run the workflow: `./run.sh`. The output GeoTIFF will be stored in `$(pwd)/data`

Use `./app/parameters.yaml` to modify the input parameters. By default, the application uses the mimicked LSTM and CHIME datasets generated by the HEATWISE project and stored on [ESA's APEX platform](https://browser.apex.esa.int/external/eoresults.esa.int/stac/collections/CHIME_and_LSTM_mimicked_reflectances_over_land_HEATWISE/items/athens-sepolia-lstm?.language=en).

## Outout

A GeoTIFF file with one bands (the ATI).
