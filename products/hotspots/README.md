# HeatWise LST Hotspot Detection

## About

The proposed hotspot detection algorithm is based on an ensemble machine learning (ML) framework that combines predictions from multiple regression models through majority voting. Its objective is to identify spatially coherent clusters of pixels whose LST are significantly higher (hotspots) or lower (coldspots) than would be expected given the thermal characteristics of their surrounding neighbourhood. The algorithm takes a single 50 m resolution LST raster as input and produces two binary outputs: a hotspot map identifying pixels with significantly higher-than-expected LST values and a coldspot map identifying pixels with significantly lower-than-expected values. To characterize the local thermal context of each pixel, a moving window approach is applied across the raster, from which 14 descriptive statistics are calculated, including measures of central tendency, variability, extrema, and distribution characteristics, such as the LST mean, variance, inter-quartile range, and maximum.

## Usage

- Build the EOAP/CWL workflow using ['xcengine'](https://github.com/xcube-dev/xcengine) and executing `./build.sh` or by using the provided `Dockerfile` in `.\app`.
- Run the CWL workflow using a cwl runner (e.g., [cwltool](https://cwltool.readthedocs.io/en/latest/)): `cwltool app/eoap.cwl#hotspot_detection`. The output will be placed in subdirectory of the working directory with a random hash identifying the workflow run.
- Run the docker container directly: `./run.sh`. The output GeoTIFF will be stored in `$(pwd)/data`

Use `./app/parameters.yaml` to modify the input parameters. By default, the application uses the mimicked LSTM data generated by the HEATWISE project and stored on [ESA's APEX platform](https://browser.apex.esa.int/external/eoresults.esa.int/stac/collections/CHIME_and_LSTM_mimicked_reflectances_over_land_HEATWISE/items/athens-sepolia-lstm?.language=en).

## Output

A GeoTIFF file with two bands (1: LST coldspots and 2: LST hotspots).
