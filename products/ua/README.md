# Heatwise WP1 Combined Product

This product combines hotspot and material information from WP1 using the Copernicus Land Monitoring Service Urban Atlas (UA) dataset as the basis layer. For each UA feature, the app calculates (i) the percentage fraction of each dominant urban material and (ii) the percentage coverage of hotspot clusters within the feature area, and adds it as new attributes.

## Usage

- Build the EOAP/CWL workflow using ['xcengine'](https://github.com/xcube-dev/xcengine) and executing `./build.sh` or by using the provided `Dockerfile` in `.\app`.
- Run the workflow: `./run.sh`. The output file will be stored in `$(pwd)/data`

Use `./app/parameters.yaml` to modify the input parameters. By default, the application uses the example data (LST clusters and dominant materials) generated by the HEATWISE project for the Sepolia test site that are available in `./data`.

## Outout

The output is an updated Urban Atlas dataset provided as a new vector file containing additional attributes that describe the material composition and hotspot coverage as areal fractions (%).
